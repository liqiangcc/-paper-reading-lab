# 架构边界

- **reading-mcp**：原文、canonical 单元、结构、TextLocator 与原始视觉。
- **paper-reading-lab**：逐句分析质量规则和最小阅读状态。
- **GitHub Issue**：当前状态入口及必要历史。

[分析协议](../learning/source-first-sentence-reading.md) 定义怎么讲清楚；[Skill](../../.agents/skills/source-first-reading/SKILL.md) 负责实际读取与保存。其他文件按需说明，不构成层层启动门禁。

本仓库不再以主动训练、盲恢复测试或知识导出作为默认学习流水线；不实现 PDF parser、平行句子 identity、完整聊天数据库或分析自动评分。

Source 事实、AI 推论和未知仍须区分。操作位置和分析摘要可以同记录分区，语义分开不等于必须分文件。历史实验保留，不反向控制日常阅读。

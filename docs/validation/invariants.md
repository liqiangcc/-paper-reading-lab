# 必须保留的约束

这些约束保护可信分析，不是每句要展示的验收清单。历史条目由原 commit 保留；当前只保留日常与基础工程所需规则。

### I-01 版本身份

阅读绑定明确 PaperRevision 与 provider identity，标题/Issue number 不替代身份。

### I-05 stale 停止

stale / identity mismatch 不做 fuzzy rebase 或生成式补文。

### I-11 精确回读

canonical TextLocator 能精确回读；页码/显示编号不足以承担 identity。

### I-15 安全边界

named-section 定位不返回未来正文；无法安全建立边界则先停。

### I-21 已揭示位置

位置单调前进；回看不把已知内容变回未知。

### I-28 先检查范围

揭示前检查授权；越界先获得用户同意并保存，原计划保留。

### I-30 仅在明确预测任务时适用

日常不运行预测流程。用户另行要求记录预测证据时，预测必须早于揭示且不能事后美化；历史记录不改。

### I-40 最小恢复状态

身份、范围、locator、契约、简短前文模型和下一动作足以恢复；不依赖完整 transcript。

### I-44 记录真实停点

当前 locator 与实际已揭示范围不能省略；不要把枚举后回读失败说成未揭示。

### I-49 状态归属

稳定文档不写实时调度；Issue 当前状态指针要核对较新控制更新。

### I-55 推导依据

重要连接追溯已读 Source，或明确是有条件推论；不把顺序当因果。

### I-58 契约版本

分析契约记录 id 与来源 commit；旧 Profile bytes/历史结果不静默改写。

### I-59 显式切换

旧 Session 采用新契约时保存一次旧/新绑定及生效 locator，不强制重读或重测。

### I-90 薄入口

Prompt 只需 repo + Issue；用户不负责粘贴 hash、locator 或长规则。

### I-91 单一规则源

分析协议负责质量，Skill 负责操作；兼容入口只指路，不增加重复流程。

### I-92 实际调用

工具可用性以本次实际需要的调用为准；不每句枚举所有工具。

### I-93 本次输出结束

不自动推进下一独立单元；也不把 STOP 解释成必须换会话。

### I-94 工程关闭证据

工程变更按 [Task closure 证据门禁](../workflows/issue-driven-workflow.md#task-closure-证据门禁) 记录实际检查、merge/main 状态；不套到每句阅读。

## 质量与检查边界

[分析协议](../learning/source-first-sentence-reading.md) 要求忠实、具体、推导不跳步、自然可读和保留未知。CI 不判断这些语义，也不证明用户能力提升。

不默认要求训练、闭卷作答、Profile 稳定化或独立会话试次。历史未测试仍为未测试，取消需求不是 PASS。公开仓库不镜像全文，分析不能冒充原文。

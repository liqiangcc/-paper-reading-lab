# 论文与阅读生命周期

本文件只保留必要语义，不再定义 Source、Profile、Artifact、训练、导出各自的必经流水线。

Source 足以支持当前阅读的条件：版本明确、身份稳定、当前单元能精确回读、范围能在揭示前确认。拿到文件不等于可安全逐句阅读；但无需预先验证整篇未读正文。

阅读可开始、连续进行、暂停或结束；状态与恢复见 [阅读状态](../learning/reading-sessions.md)。一次输出结束只等待下一句，不要求新 Session、新会话或额外验收。

Source stale、范围不明或身份冲突时停止当前读取并保存事实。历史 abandoned/contamination 不改成成功；已揭示内容不能“忘掉”再充当首次阅读。

Source/分析契约切换须显式记录，不自动重写旧引用。新 Session 使用当前分析契约，旧 Session 按授权切换；Profile stable 不是正常阅读准入条件。

阅读之后没有训练、测验或额外通关阶段。
